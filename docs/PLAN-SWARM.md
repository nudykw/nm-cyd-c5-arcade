# PLAN — `SWARM` (RTS-lite на ESP32-C5) — **виконано**

Гра в стилі StarCraft для NM-CYD-C5: **real-time з dirty-rect рендером**, 2 фракції,
4–8 юнітів на сторону, одна карта на екрані (без скролу). Етапи 1–6 закрито 2026-11-13,
всі цифри нижче **виміряні на платі**.

---

## 3. Виміри (плата NM-CYD-C5, CH340 `/dev/ttyUSB0`)

| метрика | значення |
|---|---|
| `selftest` на старті | **29/29 failed=0** |
| повний кадр при старті | **51 ms** (154 KB по SPI 40 MHz + ініціалізація) |
| fps у грі (8–12 юнітів, демо) | **170–290 fps**, кадр **1–4 ms**, 2–6 dirty-rect |
| спайк-вимір (болванки 24 шт.) | 78–92 fps, кадр 9–12 ms, 10–12 rect |
| розмір `SWARM.BIN` | **136 304 B** (13 % слота 1 MB) |
| партія AI vs AI | 250–330 с до знищення HQ |

Висновок: вузьке місце RTS на цьому залізі — **ввід і логіка, а не рендер**: dirty-rect дає запас ×5
до бюджету 30 fps навіть при 24 юнітах.

## 4. Керування

- тап по своєму юніту — вибрати; тап по землі — наказ руху/атаки (ворог під пальцем — атака);
- потягнути від землі — рамка виділення; подвійний тап по юніту — всі юніти того ж типу;
- тап по своїй будівлі — вибрати (HUD показує доступні найми);
- HUD: `BLD` (поставити барак, потім тап по місцю), `STOP`, `WRK`/`GRT`/`HVY`, `DEMO`, `EXIT`;
- UART (для перевірки без пальця): `X`/`Q` — вихід, `D` — демо, `S` — статус, `T` — робітник,
  `B` — барак, `Y` — ґрант, `A` — усі війська в атаку, `G` — робітники на родовище,
  `1`/`2`/`3` — вибрати тип юнітів, `?` — знімок екрана.

## 5. Перевірка

```bash
bash tools/test-host.sh                       # 21 тест рушія SWARM + усі інші ігри
bash tools/build-all.sh                       # dist/sd/GAMES/SWARM.BIN + dist/sdseed.bin
bash tools/flash-all.sh /dev/ttyUSB0          # лаунчер + пакет ігор (12 шт.)
python3 tools/screenshot.py /tmp/sw.png /dev/ttyUSB0

# швидка ітерація без лаунчера:
espflash flash --non-interactive --chip esp32c5 --port /dev/ttyUSB0 --flash-size 16mb \
  --partition-table partitions.csv --target-app-partition factory --erase-parts otadata \
  target/riscv32imac-unknown-none-elf/release/cyd-game-swarm
```

## 6. Відомі обмеження

1. **AI сильніший за пасивного гравця**: перша хвиля — після 90 с, до того часу треба встигнути
   поставити барак і найняти 3–6 юнітів. У дзеркальному матчі (AI vs AI) частіше виграє червона
   сторона — через «хто атакує першим, той і втрачає армію» (у AI немає мікро); на гру проти людини
   це не впливає.
2. Немає авіації, туману війни, другої карти і звуку — свідомо поза MVP.
3. Робітники гравця не тікають від ворога автоматично (у AI — тікають).
4. Тап по карті без виділення лише скидає виділення — наказу «нікуди» немає.
