# «Angry Birds» на Rust для NM-CYD-C5 (ESP32-C5)

Slingshot-гра в дусі **Angry Birds** під екран **320×240 ST7789** і резистивний тач **XPT2046**.
Pure-Rust, bare-metal: **`esp-hal 1.2.2` + `mipidsi` + `embedded-graphics`**, `#![no_std]`, без RTOS,
без LVGL, без алокатора і без `f32`/`f64` у логіці (фіксована точка `FP = 64`).

```
nm-cyd-c5-birds-rs/
├── Cargo.toml            features: framedump, demo
├── .cargo/config.toml    target riscv32imac-unknown-none-elf, runner = espflash --chip esp32c5
├── src/lib.rs            pub mod game
├── src/game.rs           фізика польоту, руйнування, падіння, свині, рахунок, бот, самотести
└── src/bin/main.rs       запечене тло (небо/пагорби/трава/рогатка), спрайти, HUD, SPI DMA, тач
```

## Збірка / заливка

```bash
cd ~/Projects/Esp32/nm-cyd-c5-birds-rs
cargo build --release                                # ~4 с інкремент
espflash flash --chip esp32c5 --port /dev/ttyUSB0 \
  target/riscv32imac-unknown-none-elf/release/nm-cyd-c5-birds-rs
```

Виміряно на платі (2026-11-12):

- образ: **70 000 B** (0.43 % від 16 MB флеша);
- повний кадр `320×240`: **36 ms**, щокадрове оновлення поля `240×240`: **27 ms** при SPI 40 MHz + DMA;
- статика у внутрішній SRAM: `150 KB` (`FB`) + `28.8 KB` (`FIELD_BG`, 4-бітне запечене тло) + `16 KB` (`LCD_BUF`);
- самотести логіки на старті: **424 перевірки, 36 мс** (друкує `BIRDS: самотести логіки: OK (424 перевірок, 36 ms)`).

## Керування

| дія | як |
|---|---|
| **тягнути птаха (сила + кут)** | натиснути **на птаха / рогатку** (радіус 34 px), потягнути вниз-вліво й відпустити |
| **швидкий постріл у ціль** | тапнути **будь-де на полі** — напрямок на палець, сила за відстанню; під час утримання видно пунктирну траєкторію |
| **пауза** | кнопка `PAUSE` / `PLAY`; тап по полі знімає паузу без пострілу |
| **перезапуск рівня** | `RETRY` (рахунок відкочується до початку рівня) |
| **нова гра** | `NEW` (з 1-го рівня, рахунок 0, рекорд сесії лишається) |
| **автогра** | `DEMO` — бот сам підбирає постріли (підсвічена золотом) |

Під час прицілювання внизу поля є шкала потужності з відсотками, на полі — пунктирна траєкторія
до першої перешкоди й кільце в точці влучання. У лівому верхньому куті — лічильник птахів `xN`.

## Механіка

- **Птах** (радіус 8 px) летить за параболою: `g = 19/64 ≈ 0.30 px/тік²`, швидкість `натяг / 4`
  (до ~11.5 px/тік на повному натягу). 4 підкроки на тік проти тунелювання крізь 12-піксельні блоки,
  пружність 0.5, легкий опір повітря, тертя/відскок об землю. Птах «засинає», коли спинився.
- **Блоки** трьох матеріалів: дерево (HP 4, 50 очок), лід (HP 2, 30), камінь (HP 8, 80).
  Урон від птаха = `clamp(швидкість·4/3, 1, 14)` — повільний дотик не ламає, швидкий зносить камінь.
  Кожен удар — білий спалах рамки.
- **Падіння**: блок без опори (знищено нижній) падає вертикально, б'є блок під собою, а падаючий блок
  або свиня, що впала з висоти, — вбиває свиню. Тому обвал вежі дає каскад очок.
- **Свині** (HP 2, 500 очок): гинуть від прямого влучання птаха, падаючого блока або власного падіння.
- **Рахунок/рекорд**: за руйнування, за свиней і бонус за рівень `500 + 1000 × невитрачені птахи`.
  `BEST` — рекорд сесії (у NVS не пишеться).

## Рівні

1. **Перший поверх** — дві дерев'яні стійки, балка, лід-кубик, 2 свині, 4 птахи.
2. **Вежа** — кам'яні опори + два дерев'яні поверхи, 3 свині, 4 птахи.
3. **Фортеця** — кам'яні стіни, лід по краях, 4 свині, 5 птахів.

Після 3-го рівня цикли знову з 1-го, але `HP` блоків і свиней росте з кожним колом (`+1` за цикл).

## Тести логіки

```bash
rustc --edition 2024 --test src/game.rs -o /tmp/birds_tests && /tmp/birds_tests
# 3 tests: selftests, політ, падіння після втрати опори
```

`game::selftest_checks` (424 перевірки) виконується **і на старті МК**:

- для кожного рівня: блоки/свині в межах поля, свині не всередині блоків, усі блоки й свині мають опору,
  блоки не перетинаються, кількість птахів > 0;
- на кожному рівні існує постріл, що влучає у споруду (`find_demo_shot`);
- політ: птах не провалюється крізь землю і не зависає (завжди завершується < 400 тіків);
- натяг понад максимум обрізається до `MAX_PULL`, відсотки потужності ≤ 100;
- демо-постріл справді руйнує блок або вбиває свиню на кожному з 3 рівнів;
- бонус за рівень нараховується рівно один раз.

## Діагностичні режими

- `--features demo` — автопілот: бот перебирає сітку точок прицілювання (9×8) і обирає постріл із
  найбільшою «вагою» (свиня = 1000+, блок = матеріал + висота), показує траєкторію й стріляє.
  Перевірено на платі: рівень 1 проходиться двома пострілами (рахунок 3600 + бонус 2500), далі бот іде
  на рівень 2 і знищує 2 з 3 свиней.
- `--features framedump` — віддає в UART чотири кадри (`SNAPBEGIN 320 240 640` … `SNAPEND 153600`):
  стартовий стан, прицілювання з траєкторією, політ після 20 тіків і картка `LEVEL CLEAR`.

## Особливості цієї плати (щоб не наступити вдруге)

- **`esp-println` тільки з `features = ["uart"]`**, не `auto`: інакше друк іде в native-USB `ttyACM0`,
  який ніхто не читає, і прошивка «зависає» на першому ж `println!` (див. `~/AGENTS.md`).
- **SPI DMA**: `Spi::with_dma(p.DMA_CH0)` + `features = ["unstable"]` у `esp-hal`; буфер `LCD_BUF`
  статичний, `SpiInterface` тримає його між передачами.
- **Тач**: `word >> 3` (не `>> 4`), differential-канали `0xD0`/`0x90`, медіана з 3 зчитувань,
  калібрування `K_X`/`K_Y` — ті самі коефіцієнти з NVS `touchcal`, що й у `nm-cyd-c5-zuma-rs`.
- **Без антиаліасингу**: спрайти й блоки малюються цілими пікселями, шрифти `6×10` / `9×18` / `10×20` —
  на 143 dpi немає «снігу» на краях.
