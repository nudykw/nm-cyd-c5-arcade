# «Zuma» на Rust для NM-CYD-C5 (ESP32-C5)

Класична **Zuma** (у дусі Astraware Zuma для Palm OS) під екран **320×240 ST7789** і резистивний
тач **XPT2046**. Pure-Rust, bare-metal: **`esp-hal 1.2.2` + `mipidsi` + `embedded-graphics`**,
`#![no_std]`, без RTOS, без LVGL, без алокатора і без `f32`/`f64` у логіці.

```
nm-cyd-c5-zuma-rs/
├── Cargo.toml            features: framedump, demo
├── .cargo/config.toml    target riscv32imac-unknown-none-elf, runner = espflash --chip esp32c5
├── src/lib.rs            pub mod game
├── src/game.rs           фіксована точка FP=64, 3 траси, фізика сегментів/розривів, бот і самотести
└── src/bin/main.rs       запечений кам'яний храм, 3D-спрайти куль, жабка, череп, SPI DMA, тач
```

## Збірка / заливка

```bash
cd ~/Projects/Esp32/nm-cyd-c5-zuma-rs
cargo build --release                    # ~4 с інкремент
espflash flash --chip esp32c5 --port /dev/ttyUSB0 \
  target/riscv32imac-unknown-none-elf/release/nm-cyd-c5-zuma-rs
```

Виміряні показники на платі:
- розмір образу: **76.2 KB** (`76 240 B`, 0.47 % від 16 MB флеша);
- повний кадр `320×240`: **36 ms**, щокадрове оновлення поля `240×240`: **27 ms (~37 fps)** при SPI 40 MHz + DMA;
- статика в внутрішній SRAM: `150 KB` (`FB`) + `28.8 KB` (`FIELD_BG`, 4-бітне запечене тло храму) + `16 KB` (`LCD_BUF`).

## Тести логіки — на хості й на старті плати

```bash
rustc --edition 2024 --test src/game.rs -o /tmp/zuma_tests && /tmp/zuma_tests
# running 3 tests ... test result: ok. 3 passed; 0 failed (0.05s)
```

При кожному старті МК виконує `game::selftest_checks` (**9367 перевірок** за ~170 мс):
- геометрія всіх 3 трас: межі поля, відстань від жолоба до жабки `>= 36 px`, відсутність накладання сусідніх витків (`>= 22 px`);
- точне вставлення снаряда перед/за кулею за знаком дотичної та миттєве зникнення групи `3+`;
- утворення розриву, магнітне притягання однакових країв назад і каскадний вибух `COMBO x2!`;
- радіусний підрив `Bonus::Bomb` із збереженням строгого інваріанта `s[i+1] - s[i] >= BALL_STEP`;
- стрес-прогін бота на всіх 3 трасах.

## Механіка та керування

| дія | як |
|---|---|
| **миттєвий постріл** | короткий тап по ігровому полю (`x < 240`) |
| **точний приціл** | затиснути стилус/палець на полі й вести — з'являється пунктирний промінь до першої кулі; відпускання = постріл |
| **зміна кулі (`SWAP`)** | тап по самій жабці в центрі **або** кнопка `SWAP` на правій панелі |
| **пауза (`PAUSE` / `PLAY`)** | кнопка `PAUSE` заморожує гру й виводить картку `PAUSED` (зняття з паузи — кнопка `PLAY` або тап по полю, без випадкового пострілу) |
| **автогра (`DEMO`)** | кнопка `DEMO` вмикає/вимикає розумного бота просто під час гри (підсвічується зеленим із золотою рамкою, перед кожним пострілом показує пунктир прицілу) |
| **нова гра (`NEW`)** | кнопка `NEW` праворуч (рекорд сесії `BEST` зберігається) |

### Траси та прогресія

1. **Stage 1 (та 4, 7…)** — *Храмова спіраль* (жабка в центрі, 4 кольори на 1-му рівні).
2. **Stage 2 (та 5, 8…)** — *Зміїний каньйон* (жабка знизу, 4 горизонтальні річкові петлі, 5 кольорів).
3. **Stage 3 (та 6, 9…)** — *Ацтекський лабіринт* (прямокутна спіраль із заокругленими кутами, усі 6 кольорів).

- **Розриви та комбо**: відрізок попереду розриву зупиняється; якщо краї розриву одного кольору — передній відрізок магнітом розганяється назад, б'ється об задній, робить каскадний вибух `×2, ×3…` і відштовхує весь поїзд від черепа.
- **Бонуси на кулях**: `Slow` (сповільнення втричі), `Reverse` (відкат усього поїзда назад), `Bomb` (вибух у радіусі `38 px` через сусідні витки).
- **Шкала `ZUMA!`**: коли заповнюється — поїзд робить ривок назад і нові кулі з тунелю більше не виходять; лишається добити залишок на полі.
- **Кулі розрізняються і кольором, і символом у центрі** (ромб, смужка, `+`, кільце, `X`, трикутник), без антиаліасингу зовнішнього краю — жодного «снігу» на 143 dpi.

## Діагностичні режими

- `--features demo` — розумний автопілот (шукає відкриті лінії прицілу у групи свого кольору, міняє кулю через `SWAP`, проходить усі 3 траси поспіль).
- `--features framedump` — після викоту стартового поїзда віддає кадр у UART (`SNAPBEGIN 320 240 640` … `SNAPEND 153600`).
